<h1 align="center">开始使用</h1>

### 使用方法

1. 下载最新版本。
2. 启动 `Launcher.exe`。
3. 手动启动游戏。
4. 游戏启动后，按 `INSERT` 键打开界面。

简体中文覆盖层的翻译表、生成方法和校验说明见
[localization/README.md](localization/README.md)。

<h1 align="center">功能</h1>

#### 玩家

- 伤害倍率
- 无敌模式
- 命中倍率
- 瞬间失衡
- 穿墙
- 无限支援点数
- 无限终结技

#### 世界

- 自动跳过
  - 过场动画
  - 对话
  - 视觉小说
  - 漫画
- 自动对话
- 宝箱传送
- 木桩敌人
- 全局速度
- 杀戮光环
- 立即胜利
- 聚怪

#### 小游戏

- 怪奇旅伴
  - 无敌模式
- 25 马赫
  - 无敌模式
- 蛇对蛇
  - 无敌模式

#### 视觉

- 自定义画质
- 视野调整
- 帧率显示
- 自由相机
- 隐藏界面
- 防止角色虚化
- UID 修改

#### 杂项

- 加载、保存和重置配置
- 自定义菜单字体
- 帧率解锁
- 时装切换
